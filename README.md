# ДЗ 3

Упаковка в docker приложения `app/` (код не изменен), счетчик хранится в redis.
Решение отдельных заданий есть в коммитах к этому репозиторию 

## Запуск

```sh
cp .env.example .env
docker compose up -d --build
docker compose down
```

### Запуск скрипта для проверки

```sh
python3 scripts/check.py # (Python 3 - стандартная библиотека)
```

## Настройка .env

| Переменная | Значение по умолчанию | За что отвечает |
| --- | --- | --- |
| `APP_PORT` | `8080` | локальный порт сервиса |
| `GREETING` | `Hello, Docker!` | приветствие, которое возвращает сервис |
